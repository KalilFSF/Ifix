# Certificado público CA

Opcional: coloque aqui a CA pública real como `aiven-ca.pem` e configure MYSQL_SSL_CA=backend/certs/aiven-ca.pem. Nunca coloque chave privada. Alternativa recomendada: MYSQL_SSL_CA_PEM com o PEM completo no painel Vercel, sem arquivo local. Não há certificado fictício no projeto.
